## 已保留的功能

- 原图，以及边缘提取、视觉增强、像素画、复古四种滤镜。
- 自动与手动白平衡；手动2500–10000K和AB/GM调节，环境预设已删除。
- 八目标、4096段/帧轮廓缓存和128标签，三色识别及坐标、形状、标注。
- ISP菜单、50%半透明面板和按钮、完整回退按钮；弹出菜单覆盖重叠的上下栏区域。
- 上下栏保留原有样式及信息，仅把打开菜单的操作提示更新为左滑；功能库仍可显示/隐藏上下栏。
- 主菜单“功能库”按钮下方有独立“画面信息”，汇总状态、FPS、DET、LAT及当前/峰值帧龄、丢弃帧、读取溢出和显示欠读。

在预览画面单指向左滑动至少100像素，纵向偏移不超过80像素，并在1秒内松手，即打开右侧菜单。静止长按不打开菜单；菜单内部的长按连续调节保持原样。打开手势不会继续点击新菜单按钮。

帧龄单位为源帧，LAT为识别处理耗时，两者不是同一个指标。诊断计数显示最高255，原32位计数器继续计数。隐藏上下栏时，画面信息页仍显示完整读数。

视觉增强沿用共享单窗口实现，与原始Sigma+Sobel不逐像素一致。预览由RTL测试画面生成，不是实拍。

## 比特流与重新构建

普通镜像：DSI_ISP_RGB_INTEGRATED_SC500_7inch.bit；压缩镜像：DSI_ISP_RGB_INTEGRATED_SC500_7inch_compress.bit。两者对应本包同一份源码，校验值见SOURCE_VALIDATION.json。

器件PH1P35MDG324，SC500CS摄像头，7寸DSI、1024×600。解压至较短路径，例如C:\FPGA\ISP_RGB，避免TD的长路径读取问题。用TD 6.2.168116打开td_project/wb_ui_dsi.al，或在工程根目录运行powershell -ExecutionPolicy Bypass -File build.ps1 -TdHome C:\APP2\ALTD。

build.ps1仅在最终建立/保持/周期检查非负、无布线冲突和开路、资源未超限后复制镜像。实际硬件仍需确认触摸方向、画面稳定性及识别阈值。
